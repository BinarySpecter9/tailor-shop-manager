## 📖 About

**Tailor Shop Manager** replaces the paper register most tailoring shops still rely on. It keeps every customer, every measurement, and every day's stitching progress in one place — and even answers "how much of my order is done?" for you.

## ✨ Features

- 👥 **Customer records** — name and mobile number for every customer
- 📏 **Measurements (naap)** — recorded separately per garment: kameez, salwar, pant, shirt — with pattern notes, quantity, and expected delivery date
- 📅 **Daily progress log** — at evening pack-up, log what got stitched: how many garments completed, how many remain
- 🤖 **AI order-status assistant** — look up any customer by mobile number and instantly see work done, work remaining, and expected completion time
- 🔍 **Customer search**, editable records, light/dark themes
- 📱 **Mobile-first design** — big touch targets, bottom navigation, built for the shop floor

## 🛠️ Tech

- Mobile-first web app with a real backend (customer, measurement, and progress data persists across devices)
- Currently a working web app — Android packaging (Capacitor) planned for the Play Store release
